# spbu-deep-learning-course

Домашние задания по курсу «Прикладные задачи машинного обучения».

## ДЗ №1. Классификация пород кошек и собак

**Задание.** Дообучить предобученные сверточные сети на датасете
[Oxford-IIIT Pet](https://www.robots.ox.ac.uk/~vgg/data/pets/) (37 пород кошек
и собак) и сравнить две архитектуры. В работе нужно:

- заменить классификатор у моделей с весами ImageNet и обучить его при
  замороженном backbone;
- применить итеративную аугментацию (слабые → средние → сильные
  преобразования);
- выполнить итеративную разморозку: сначала последний блок, затем вся сеть,
  с разными learning rate для групп слоёв и `ReduceLROnPlateau`;
- использовать псевдолейблинг: разметить неразмеченный пул и дообучиться на
  объединении с train;
- сравнить модели по accuracy, macro-precision, macro-recall и macro-F1
  на validation и test, разобрать ошибки по классам и построить матрицы
  ошибок.

**Решение:** [hw1_pet_classification/hw1_pet_classification.ipynb](hw1_pet_classification/hw1_pet_classification.ipynb)

## ДЗ №2. Агрегация ответов асессоров

**Задание.** На датасете [Relevance-2](https://github.com/Toloka/crowd-kit)
(оценки пар «поисковый запрос — документ», собранные в проекте Relevance 2
Gradations) исследовать структуру краудсорсинговой разметки и сравнить методы
агрегации ответов:

- посчитать базовые статистики: число оценок на объект, активность
  асессоров, баланс классов, попарную согласованность, точность отдельных
  исполнителей;
- проверить, какие особенности данных соответствуют реальной
  краудсорсинговой разметке;
- реализовать Majority Vote и Weighted Majority Vote (веса — точность
  асессора на калибровочной выборке);
- применить Dawid–Skene из `crowd-kit`;
- сравнить методы по accuracy, macro-precision, macro-recall и macro-F1 на
  отложенной тестовой части, разобрать метрики по классам и матрицы ошибок.

**Решение:** [hw2_assessor_aggregation/hw2_assessor_aggregation.ipynb](hw2_assessor_aggregation/hw2_assessor_aggregation.ipynb)

## Запуск ноутбуков

- ДЗ №1 рассчитано на GPU (проверялось на Tesla T4 в Google Colab); набор
