# spbu-deep-learning-course

Домашние задания по курсу «Прикладные задачи машинного обучения».

## ДЗ №1

Найти и согласовать датасет.
Обучить как минимум 2 разных архитектуры сетей, использовать разобранные
на занятии техники:

- Итеративная аугментация
- Итеративная разморозка слоев с адаптивным lr
- Псевдолейблинг

**Решение:** [hw1_pet_classification/hw1_pet_classification.ipynb](hw1_pet_classification/hw1_pet_classification.ipynb)

## ДЗ №2

Сгенерировать или найти датасет асессорских оценок, посчитать по нему разные
статистики и описать почему они похожи на реальные данные.
Применить методы агрегации:

- Majority Vote
- Weighted Majority Vote
- (после след занятия) Dawid Skene

Замерить качество, сделать выводы

**Решение:** [hw2_assessor_aggregation/hw2_assessor_aggregation.ipynb](hw2_assessor_aggregation/hw2_assessor_aggregation.ipynb)

## Запуск ноутбуков

- ДЗ №1 рассчитано на GPU (проверялось на Tesla T4 в Google Colab); набор
  данных скачивается автоматически в папку `data/`.
- ДЗ №2 выполняется на CPU примерно за 1–2 минуты, датасет скачивается
  через `crowd-kit` при первом запуске.
